Hold right ⌥ to dictate. The writing popover shows a live transcript using your Mac’s English or French speech model.

Enable dictation

  1. In Settings › Dictation, turn on Enable voice dictation and allow microphone access.
  2. Under Speech models, download the language you want to use if macOS has not installed it yet.

Insert or edit with your voice

  1. Focus a text field and hold right ⌥ while you speak. A closed popover opens in Insert. If the popover is already open, it keeps the selected mode.
  2. Release to finish recording. Review the transcript and correct any words in the popover.
  3. In Insert, press Return to draft from what you said, or choose Insert transcript to put your words into the field. Switch to Edit to apply a spoken instruction to existing text. Press Esc to discard the draft.

For hands-free dictation, tap right ⌥ to open the popover. Choose Record to start and Stop to review the transcript. Tap the key or choose a mode in the popover before submitting.

Choose a language

Remora uses one language at a time. Pin a language in the menu bar or use the language button in the popover. With Automatic selected, Remora uses the last language you dictated in that app, then the default from Settings. Choose English (US) or French (France).

Use OpenAI for the final transcript

To enable it, open Settings › Dictation › OpenAI transcription, enter an OpenAI project API key with write access to /v1/audio/transcriptions, and choose Save and enable. The key is stored in the macOS Keychain. Use a project in your linked API organization to draw on its credits.

Your Mac generates the live preview. For eligible recordings, Remora sends the audio and a language hint to gpt-transcribe when you choose Insert transcript with the unchanged transcript. Remora uses the Mac transcript if the upload fails, the window changes, capture is paused, or the window is private, excluded, or unverifiable. Drafting and editing use the reviewed text. Dictation audio and privacy

Choose Remove key to disable cloud transcription. You can also delete the dev.remora.dictation-transcription item for account openai in Keychain Access.

Transcript cleanup

Clean up transcripts is on by default. When you insert an unchanged transcript, a model pass removes fillers and fixes punctuation while keeping the spoken language. This can send transcript text to OpenAI in an allowed context. If you correct the transcript before inserting it, your corrections are kept as typed.

Turn cleanup off to insert the transcript directly. In private, excluded, or unverifiable contexts, cleanup uses the on-device model if available. See model routing.
