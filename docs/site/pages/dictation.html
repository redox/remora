Hold right ⌥ to dictate. The writing popover shows a live transcript using your Mac’s English or French speech model.

Enable dictation

  1. In Settings › Dictation, turn on Enable voice dictation and allow microphone access.
  2. Under Speech models, download the language you want to use if macOS has not installed it yet.

Draft or rewrite with your voice

  1. Focus a text field and hold right ⌥ while you speak. A closed popover opens in Draft. If the popover is already open, it keeps the selected mode.
  2. Release to finish recording. Review the transcript and correct any words in the popover.
  3. In Draft, press Return to draft from what you said, or switch to Insert and press Return to insert the text exactly as shown. Switch to Rewrite to apply a spoken instruction to existing text. Press Esc to discard the draft.

For hands-free dictation, tap right ⌥ to open the popover. Choose Record to start and Stop to review the transcript. Tap the key or choose a mode in the popover before submitting.

Choose a language

Mac speech recognition uses one language at a time. Pin English (US) or French (France) in the menu bar. The popover also offers a language button when OpenAI transcription is off. With Automatic selected, Remora uses the last language you dictated in that app, then the default from Settings.

Use OpenAI for the final transcript

To enable it, open Settings › Dictation › OpenAI transcription, enter an OpenAI project API key with write access to /v1/audio/transcriptions, and choose Save and enable. The key is stored in the macOS Keychain. Use a project in your linked API organization to draw on its credits. When automatic meeting recording is on, Remora also sends eligible meeting app audio and unmuted microphone audio to OpenAI during calls. Meeting audio and privacy

Your Mac generates the live preview. For eligible recordings, Remora sends the audio to gpt-transcribe when you release the key or click Stop with Transcribe on stop enabled. Turn this on in Dictation settings for a previously saved key. OpenAI detects the language from the audio. Remora uses the Mac transcript if the upload fails, the window changes, capture is paused, or the window is private, excluded, or unverifiable. Drafting and editing use the reviewed text. Dictation audio and privacy

Choose Remove key to disable cloud transcription. You can also delete the dev.remora.dictation-transcription item for account openai in Keychain Access.

Transcript cleanup

Clean up Mac transcripts uses Apple Intelligence to remove fillers and fix punctuation before review. OpenAI transcripts go directly to the editor. Insert preserves subsequent corrections.

Turn cleanup off to review the original Mac transcript. Remora also uses the original if the local model is unavailable. See model routing.
