Remora stores screen memory in a local SQLite database on your Mac. A task that uses a cloud model can send the excerpts it needs directly to OpenAI under your ChatGPT account.

What Remora captures

Remora reads text the frontmost window exposes to macOS Accessibility and text you copy. It also records available app, window, site, and focus metadata. Capture is text-based, with no screenshots, screen recording, or keystroke log.

Built-in protections skip secure fields, password managers, private browser windows, known banking or sign-in pages, and clipboard items marked concealed or transient. Your exclusion rules apply in addition to those protections. When Remora cannot verify that a context is allowed, it skips capture.

Recognized secrets such as card numbers, API tokens, and private keys are replaced with [redacted] before storage. Ordinary names, email addresses, and phone numbers can remain in captured text.

How model routing works

ContextRewrite access
Allowed windowThe field and relevant window context or memory may be used with the configured model.
Capture paused in an otherwise allowed windowA cloud request may contain the current field text alone.
Excluded, private, or unverifiable contextSupported field operations use the on-device model. Draft and insert can use ChatGPT with only the typed or reviewed spoken prompt you submit. The request includes no field text, app or site information, or memory.
Secure field, password manager, or vault pageThe rewrite is refused.

Optional transcript cleanup can use a model after transcription. Background memory and chat can send relevant allowed excerpts to OpenAI. On request, routine discovery can include window titles, app or site names, dates, and focus times in the chat request.

Dictation audio

The live transcript uses Mac speech recognition. Drafting and editing use the reviewed text. If you save an API key for OpenAI transcription, choosing Insert transcript with an eligible, unchanged transcript sends the completed recording and a language hint to api.openai.com/v1/audio/transcriptions under that API project. Paused, private, excluded, and unverifiable contexts use Mac speech recognition. Remora keeps audio in memory, discards it when the draft is dismissed, and stores the key separately in the macOS Keychain.

Where data is kept

  • ~/Library/Application Support/Remora/remora.sqlite holds captures, memory, chat history, and imported meetings.
  • ChatGPT and Granola credentials are stored separately in the macOS Keychain.
  • Remora logs operational events, counts, and codes. Captured text, model prompts and replies, transcripts, and credentials are excluded from logs.

See retention and delete all data.

Imported meetings

Meeting imports use a separate search index on this Mac. Quill and other local sources connect over loopback. If you connect Granola, mcp-auth.granola.ai handles sign-in and mcp.granola.ai receives your Granola session credential, sync filters, and meeting IDs for read requests.

Chat access is off by default. If you turn it on, interactive Remora chat can send relevant excerpts and their meeting titles, dates, and IDs to OpenAI under your ChatGPT account. Control chat access

Network and connected clients

  • OpenAI handles sign-in and model requests under your ChatGPT account.
  • Configured app updates use GitHub Releases. macOS gets dictation language models from Apple.
  • Connected MCP clients read through a local server and control any onward transfer.

Remora has no backend, telemetry, analytics, or crash reporting service. This documentation site is static and performs searches in your browser.
