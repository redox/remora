Remora’s MCP tools read captures, activity, derived memory, and usage. The server accepts tool arguments as JSON objects. Time arguments use Unix seconds.

Captures and activity

search_memory
Requires query. Optional app, since, until, and limit. Returns snippets and snapshot IDs. Default limit 10, maximum 20.
get_snapshots
Requires ids with up to 10 snapshot IDs. Returns text capped at 20,000 characters per snapshot, with a truncation flag.
read_session
Requires app, start, and end. Optional limit. Returns captures for one app in chronological order, capped at 2,000 characters each. Default limit 10, maximum 20.
get_recent_activity
Optional limit. Returns recent snapshots and focus activity from the last two hours. Default limit 12 per list, maximum 20.

For example, call search_memory with the arguments below. Pass matching IDs to get_snapshots if you need more than the snippets.

{
  "query": "Thursday review",
  "app": "Safari",
  "limit": 5
}

Derived memory

get_chronicle
Requires level (hour, day, week, month, or year). Optional date and count. Returns period summaries newest first. Default count 1, maximum 24.
get_working_memory
Optional limit. Returns recent threads by relevance. Default limit 12, maximum 20.
get_attention_context
Takes an empty object. Returns recent focus, relevant working memory, the latest hour summary, open items, and a memory digest when available.
search_wiki
Requires query. Optional type and limit. Returns matching pages and facts. Default limit 10, maximum 20.
get_wiki_page
Requires slug. Set include_history to true to include previous facts. Returns one page with its facts and source references.
list_wiki
Optional type, sort (recent or mentions), limit, and offset. Default and maximum limit 20.

Wiki tools accept person, project, topic, tool, or org as a type filter.

Usage

get_usage returns model call counts, token counts, and estimated costs. It takes optional since (default seven days ago) and group_by (day, job_type, or model, default day). The cost is an API-equivalent estimate. A null estimate means there is no price entry for the model.
