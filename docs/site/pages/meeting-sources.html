Import meeting notes and transcripts into Remora and search them on your Mac. Remora reads the text available from the meeting app and stores a local copy.

Connect Quill Meetings

  1. In Quill › Settings › MCP Server, turn on the MCP server and choose Enable local HTTP server. Select Copy local HTTP URL.
  2. In Remora › Settings › Meeting sources, choose Quill Meetings and paste the URL into Local MCP URL.
  3. Set Import meetings since and choose Connect. Keep Quill running for sync.

Copy the URL from Quill again if its port changes. Quill’s MCP setup guide

Connect Granola

  1. In Settings › Meeting sources, choose Granola and set Import meetings since.
  2. Choose Sign in to Granola. In your browser, sign in with the account that has access to your meetings and authorize Remora.
  3. Return to Remora and check the sync status under Connected sources.

Granola returns meetings from the active workspace according to your plan and workspace permissions. Basic provides accessible notes from the last 30 days. Transcript access requires a paid plan with the appropriate permissions. Granola’s MCP access rules

Connect a compatible local MCP server

In Settings › Meeting sources, choose Local MCP and enter the server’s Streamable HTTP URL with an explicit port, such as http://127.0.0.1:8080/mcp. Set Import meetings since and choose Connect.

Use a loopback endpoint. The server needs a compatible read tool such as list_meetings that returns stable meeting IDs, titles, and dates. Include notes or transcripts in the listing or expose compatible read tools such as get_minutes and get_transcript.

Sync and search meetings

Remora checks connected sources about every 15 minutes while it is running. After a successful sync, it checks from two days before the last sync so it can pick up changes to recent meetings. To import older history or refresh older edits, choose an earlier Import meetings since date and select Sync beside the source. The history available to import depends on the provider and its limits.

Use Search meetings to find words in imported titles, notes, and transcripts. Select a result to read it. A Quill import with a supported meeting ID also offers Open in Quill.

Allow chat to search imports

Chat access is off by default. In Settings › Meeting sources, turn on Let Remora chat search imported meetings and choose Allow. Then ask an interactive chat question with a meeting name or keyword, such as “What did we decide about pricing in the launch review?”

Relevant meeting excerpts can be sent to OpenAI under your ChatGPT account. The imports live in a separate search index accessible from Meeting sources and, with your permission, interactive Remora chat. The bundled MCP server serves screen memory to other AI apps. Meeting data and privacy

Pause, forget, or disconnect

  • Use Remora’s Pause menu to suspend sync and chat searches of meetings. Existing imports remain available in Settings and follow your exclusions.
  • Open an imported meeting and choose Forget… to remove its local copy and skip it on future syncs.
  • Choose Disconnect… next to a source and confirm to stop sync and remove that source’s imports from Remora. To remove all imports and sources, use Settings › Privacy › Delete all data….

Forget and disconnect affect the copies in Remora. Manage the originals in your meeting app. If a meeting is deleted there, use Forget… to remove the copy from Remora. Forgetting a meeting, removing its source’s imports, or turning off chat access stops Remora from replaying earlier chat to the model.
