Install Remora in Applications and grant Accessibility so it can read window text and write into text fields.

Requirements

  • macOS 26 or later.
  • A plan that supports Sign in with ChatGPT for cloud model tasks.
  • Apple Intelligence for tasks that require the on-device model. This matters for rewriting and dictation cleanup in private, excluded, or unverifiable contexts.

Install Remora

  1. Download the Remora disk image (.dmg) from @RELEASES@ when a release is available.
  2. Open the disk image and launch Remora. Accept Move to Applications, or drag the app into Applications before opening it.
  3. Run one copy of Remora at a time. Use the copy in /Applications or ~/Applications for normal work.

First run

  1. Grant Accessibility in System Settings. Remora uses it to read the frontmost window and insert text in other apps.
  2. Review the built-in capture protections and your own exclusions.
  3. Choose Continue with ChatGPT to authorize model access in your browser. Choose Later to postpone sign-in.
  4. After signing in, try the rewrite key in the practice field. Enable the microphone if you want dictation and allow notifications if you want macOS alerts.

To reopen this flow, choose Settings › General › Show onboarding again. Microphone access is for dictation. Remora requires neither Screen Recording nor Input Monitoring nor Full Disk Access.

Updates

An installed release with updates configured checks hourly. Automatic updates wait until you quit or Remora is idle and has finished its current work. In Settings › General, use Check for Updates… or change Install updates automatically.

Uninstall Remora

  1. Disconnect meeting sources in Settings › Meeting sources and AI clients in Settings › MCP.
  2. Quit from the menu bar and remove Remora.app from Applications.
  3. To remove local data and logs, delete ~/Library/Application Support/Remora/ and ~/Library/Logs/Remora/.
  4. To remove stored credentials, use Keychain Access to delete dev.remora.Remora.siwc for account chatgpt. If present, also delete dev.remora.meeting-import for account granola and dev.remora.dictation-transcription for account openai.

Build from source

Clone the repository. Copy Config/Local.xcconfig.example to Config/Local.xcconfig and select your development team or ad-hoc signing. macOS ties Accessibility grants to the app signature, so a stable development identity makes rebuilds easier to test.

brew install xcodegen
make test
make build

The Debug app is at build/Build/Products/Debug/Remora.app.
