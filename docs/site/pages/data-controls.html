Pause capture for a while, exclude a context going forward, forget specific captures, or erase Remora’s local memory.

Pause capture

Open the menu-bar Pause menu or use Settings › Privacy. Choose 15 minutes, one hour, until 08:00 tomorrow, or indefinitely. Choose Resume to resume early. The capture indicator shows the current state.

A rewrite while paused can still use field text in an otherwise allowed window. See model routing.

Pause discards pending meeting recordings and suspends meeting sync, meeting searches from chat, and recording searches from MCP clients. You can still browse existing imports in Settings › Meeting sources. Manage meeting imports

Exclusion rules

In Settings › Privacy, add one case-insensitive exclusion per entry. For the current window, the capture menu can also offer Never capture this app or Never capture this site.

Rule exampleMatches
example.comA domain and its subdomains.
app:SlackAn app name.
title:private notesWindow titles containing the text.
url:/account/Page addresses containing the text.
path:/personal/Document paths containing the text.

Some AI chat apps and sites and terminal apps are seeded as removable exclusions. Built-in protections for sensitive contexts apply independently. Adding an exclusion stops new capture for matching contexts and hides matching past captures from retrieval. Previously derived memory can remain on disk.

Forget specific captures

In chat, ask “Forget what you saw in Safari about the travel booking yesterday.” Review the proposed forget action before confirming it. Remora deletes the matching captures and removes memory that was derived only from them. Review your identity if it still mentions that context.

Chat messages from before the forget stay visible until you clear the chat. Remora stops replaying those messages to the model in future turns.

Delete all data

In Settings › Privacy, choose Delete all data… and type yes. This permanently deletes captures, activity history, summaries, wiki, identity, chat history, reminders, recorded meetings and imported meetings. Remora also clears delivered notifications, disconnects meeting sources, and turns off chat access to imports and recording access for chat and MCP. Exclusions and other preferences are kept.
