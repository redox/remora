Remora’s rewrite key works in a focused text field. Double-tap right ⌥ by itself to write into that field. Tap once to open the writing popover.

Choose what to rewrite

Field stateWhat Remora does
The field starts with /q and a questionAnswers the question and replaces it with the answer.
There is a selectionRewrites the selection.
There is no selectionDrafts from available context and inserts at the caret, keeping the existing text.
No text field has focusOpens chat when the current app and context allow it.

A Writing… badge appears near the caret. Press Esc or click the indicator to cancel. Remora waits for the complete result before it edits the field. Use ⌘ Z if the host app supports undo.

Continue text at the cursor

Place the caret (the text cursor) where you want to continue a sentence or fill a gap, then double-tap right ⌥ without selecting anything. Remora uses the text before and after the caret to draft just the new words. In an empty field, it drafts from available context, such as the email thread you’re replying to.

If the caret moves while Remora drafts, or if Remora can’t locate it in a field that already contains text, the write is skipped.

Rewrite mode

  1. Select the text you want to change and tap right ⌥ to open the writing popover in Rewrite.
  2. In the popover, enter an instruction such as Make this more direct or Translate to French.
  3. Press Return or choose Rewrite selection. The popover stays open so you can refine the new text. Press Esc or click outside to close it.

With no selection, tap right ⌥ once to open the popover and again to switch to Rewrite. Enter an instruction and choose Apply rewrite to rewrite the whole field. Use ⇧ Return to add a line to an instruction and Undo or ⌘ Z to undo the last edit while the popover is open.

With dictation enabled, hold right ⌥ to speak an instruction, then release to review it. Select Rewrite before pressing Return to apply the instruction.

Draft text

With no selection, tap right ⌥ to open the popover in Draft. Type or dictate what you want Remora to write, then choose Draft and insert or press Return. To draft a replacement for a selection, switch to Draft before submitting. Choose Insert transcript to put your spoken words into the field.

Ask in a field

At the start of an empty field, type a question after /q and double-tap the rewrite key.

/q What did we decide about the Thursday review?

Remora uses available context to answer in place. For follow-up questions, use chat.

Privacy and permissions

Secure fields and password managers refuse the rewrite key. In other places Remora doesn’t capture, Draft and insert can send only your typed or reviewed spoken prompt to ChatGPT. Operations that use the contents of the field need the on-device model there. While capture is paused in an otherwise allowed window, a cloud rewrite can use the field alone.
