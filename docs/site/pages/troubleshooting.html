Check the affected permission, shortcut, or service first. Remora’s menu bar shows capture and sign-in status.

Rewrite key does nothing or beeps

  1. Open Settings › Shortcuts and check the configured key. Tap it without holding another key.
  2. Try the practice field in Settings › General › Show onboarding again. If needed, use Settings › Privacy › Re-grant under Accessibility.
  3. Try another ordinary text field. Secure fields and password managers refuse the key. Another app using the same shortcut or an unresponsive editor can also interfere.

An app or page is missing from capture

Open the Remora menu and check the capture status. Review Settings › Privacy for paused capture or a matching exclusion. Private windows, password managers, and unverifiable pages remain protected. If memory is recent, give background processing time to build chronicles and wiki pages.

Dictation does not start

In Settings › Dictation, enable voice dictation, check microphone access, and confirm the speech model is installed. In Settings › Shortcuts, check that the rewrite key and Hold opens the popover are enabled. You can also tap the key to open the popover and try Record.

ChatGPT limit or sign-in error

Check sign-in under Settings › Account. If the plan’s allowance is exhausted, open Settings › Usage › Manage usage to check your ChatGPT allowance. Background work backs off until it can retry.

A brief or notification is missing

Send a test from Settings › Notifications to check macOS notification permission. For a missing brief, also check that proactive messages and background memory are on, that recent captured activity exists, and that the catch-up window has not closed.

An MCP client has no results

Launch the installed Remora app once to initialize or update the database. Check the client in Settings › MCP, update its registration if it points to another copy, then restart the client. Check capture status and exclusions if the server connects but results are empty.

Meeting imports are missing

Check the sync status under Settings › Meeting sources. For Quill, keep it running and copy its current local HTTP URL. For Granola, check the active workspace and its MCP permissions, or use Sign in to Granola again if the connection expired. Find diagnostic logs

Use Settings › Logs to open the log folder, open Console, or export diagnostics from the last 24 hours. Logs hold operational events, counts, and codes.
