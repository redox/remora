The bundled MCP server gives a connected AI client read-only access to Remora memory over local standard input and output.

Use Settings › MCP to share screen memory with an AI client. Use Settings › Meeting sources to bring notes and transcripts into Remora from a meeting provider. Imported meetings are available in Meeting sources and, with your permission, in Remora chat. Import meeting notes

Connect a client

  1. Run the installed copy of Remora once so it can create its local database.
  2. Open Settings › MCP and choose Connect for Claude Code, Claude Desktop, Cursor, or Codex.
  3. Restart the client if prompted. Look for the server named remora in the client’s MCP settings.

Use Update if the client points to another Remora copy. Use Disconnect… to remove Remora’s registration, then restart the client to reload its configuration. Where Remora edits a config file directly, it backs it up and changes only the Remora entry.

Other clients

Use Other apps › Copy config to copy a snippet with the exact executable path. For a client that accepts JSON with an mcpServers object, merge the Remora entry into its existing configuration.

{
  "mcpServers": {
    "remora": {
      "command": "/Applications/Remora.app/Contents/MacOS/remora-mcp"
    }
  }
}

The example assumes a system-wide Applications install. Use the path from Copy config for a copy in your personal Applications folder. The server takes no arguments and can read an initialized database while the menu-bar app is closed.

Query memory

Try asking your client “Use Remora to find when I last saw the Thursday review notes.” A client can search for snippets, then fetch the snapshots for matching IDs. See the MCP tool reference for inputs and limits.

Trust and privacy

Remora applies current exclusions when serving memory. The server marks captured text as untrusted data. A connected client controls what it does with returned data, including whether it sends it to a model provider. Disconnect clients you no longer want to have access.
