Remora captures allowed text while you work and turns it into summaries, wiki facts, and open items. Chat, rewrites, and connected clients can draw on that memory.

What memory contains

ObjectWhat it contains
CapturesText from allowed windows and clipboard items, with available time and app metadata.
ChroniclesSummaries organized into periods. Browse by day in Settings or request a period in chat or over MCP.
WikiPages about people, projects, topics, tools, and organizations. Facts retain source references when available.
Working memoryRecent threads, commitments, and items that may need attention.
IdentityA profile for chat and rewrites. Edit it in Settings › Identity to correct what Remora knows about you.

Browse memory

Open Settings › Memory and use Browse to switch between the wiki and chronicles. In chat, ask for a recent summary or use a title, person, or app name to narrow the search.

Track time by project

Use Time rules in Settings › Memory to associate activity with a project. Remora uses recorded focus time and the rules to build a time ledger. Ask chat “How much time did I spend on the website project this week?”

Retention and background work

Raw captures are kept for 30 days by default. Older captures become eligible for deletion once summarized, except when cited by a wiki fact or open item. Derived memory stays until you delete it.

Settings › Memory controls background processing, raw capture retention, and the language used for generated memory. To stop collecting new text as well, pause capture. Background model work has a daily token budget and backs off when your ChatGPT plan reaches its usage limit.
