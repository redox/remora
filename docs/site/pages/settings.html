Usage and cost

The Usage tab estimates what a call would cost at API list prices. Remora’s model calls use the allowance on your ChatGPT plan. Use Manage usage to check that allowance with ChatGPT. If a model has no price entry, the estimate is unavailable.

The default daily background budget is 750,000 tokens. Background jobs back off when the plan’s usage limit is reached. Interactive chat can still run while the background budget is exhausted, subject to your plan’s limits.

Use Edit price table… to override prices locally at ~/Library/Application Support/Remora/model-prices.json. Remora bundles its price table.
